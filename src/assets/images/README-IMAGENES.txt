ZONA EDITABLE — IMÁGENES REALES
================================
Coloca aquí las fotografías reales del restaurante. Mientras no
existan, cada <img> del sitio tiene un atributo onerror que carga
una imagen de stock temporal desde Unsplash, para que el sitio
jamás se vea "roto" durante la edición.

Reemplaza estos archivos (mismo nombre, cualquier proporción similar
a la indicada funciona bien):

  hero-lenador.jpg            -> Foto principal del home (1600x900 aprox.)
  interior-restaurante.jpg    -> Interior del local
  nosotros-hero.jpg           -> Foto de portada de "Nosotros"
  cocina-lena.jpg             -> Horno/fogón de leña
  menu-hero.jpg                -> Portada de la página de menú
  galeria-hero.jpg             -> Portada de la galería
  reservas-hero.jpg            -> Portada de reservas
  contacto-hero.jpg            -> Portada de contacto / fachada
  fachada-restaurante.jpg      -> Fachada del local
  evento-familiar.jpg          -> Foto de ambiente/familia
  og-cover.jpg                 -> Imagen para compartir en redes (1200x630)

  menu/*.jpg                   -> Una foto por cada plato definido
                                   en js/menu-data.js (el nombre de
                                   archivo debe coincidir con el
                                   campo "image" de cada plato)

  galeria/*.jpg                -> Fotos adicionales libres para la
                                   página de galería (opcional, ya
                                   hay ejemplos usando fotos de /menu)
